**submit calls** counts runs where the agent chose `submit_solution`; **graded** counts runs that produced a candidate at all, which includes final-answer turns and candidates that failed to compile. A run is only costed and scored if it is graded, so the last two cost columns are over graded runs.

**Infrastructure failures: aegis-level3 1/5.** These runs ended on a relay error (Cloudflare 52x) or the adapter wall-clock budget, which says nothing about the agent or the protection. They are counted in the run totals above and must be excluded before comparing arms; a cell with more than one of them needs to be rerun, not interpreted.

**aegis-level3 1/5 run(s) have no ledger.** They produced no candidate at all, so they carry neither a score nor a cost; every mean above is over the runs that did produce one. Where those counts differ between profiles, part of any cost difference is a capability difference rather than a protection cost.

**Cost delta (self-reported tokens, all graded runs).** aegis-level3 **2.12×** baseline (1008253 vs 474665 tokens). This is the number the harness exists to measure. Read it as a magnitude, not as a success-rate result: at this N a pass-rate difference is inside the interval, and the protocol's [statistical power](../benchmark-protocol.md#statistical-power-which-number-carries-the-result) section says how many runs a success-rate claim would need.

## What this shows

- whether a real model can produce a graded submission on a deliberately non-standard task, and at what measured cost (wall clock, and oracle queries where the access mode counts them) and self-reported cost (tokens, tool calls);
- whether the protected profile changes either, with the variance the repetitions actually exhibit;
- the probe's artifact size difference between the two profiles.

## What this does **not** show

- **No effectiveness claim.** N is small and only one task and one model were run; the pass column describes what this agent could do, not what a protection prevented.
- No claim about other attacker classes or larger models.
- Token figures include an estimate for calls aborted by the reasoning watchdog (`tokens_source` and `aborted_tokens_estimate` in the JSONL mark the share).
- Model and relay drift: rerunning later may produce different costs for the same model id.
