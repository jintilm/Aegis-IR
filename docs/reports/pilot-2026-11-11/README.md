## What this does **not** show

- **No protection effect is measurable in this run at all.** The agent's workspace held an oracle shim whose behaviour is identical in every artifact profile; it could not inspect the artifact, so levels 1–3 presented exactly the same information as the baseline. A level-vs-baseline difference here is noise, not evidence. Protection comparisons need `--access binary`.

- **No effectiveness claim.** N is small, only one task and one model were run, and the model sits at or near the floor on this task; a 0% vs 0% comparison cannot demonstrate a protection effect.
- No claim about other attacker classes or larger models.
- Token figures include an estimate for calls aborted by the reasoning watchdog (`tokens_source` and `aborted_tokens_estimate` in the JSONL mark the share).
- Model and relay drift: rerunning later may produce different costs for the same model id.
