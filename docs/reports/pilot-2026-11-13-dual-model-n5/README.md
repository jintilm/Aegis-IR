**submit calls** counts runs where the agent chose `submit_solution`; **graded** counts runs that produced a candidate at all, which includes final-answer turns and candidates that failed to compile. A run is only costed and scored if it is graded, so the last two cost columns are over graded runs.

**Cost delta (provider-metered token floors — requests that were abandoned before usage arrived are not in the totals).** deepseek-flash `aegis-level3` **3.03×** baseline (636195 vs 210224 tokens); deepseek-v4-pro `aegis-level3` **2.15×** baseline (909318 vs 422646 tokens). This is the number the harness exists to measure. Read it as a descriptive magnitude, not as a success-rate result: at this N a pass-rate difference is inside the interval, and the protocol's [statistical power](../benchmark-protocol.md#statistical-power-which-number-carries-the-result) section says how many runs a success-rate claim would need.

**The token ratio does not hold the success criterion fixed.** Observed pass counts differ between arms: deepseek-flash `aegis-level3` 0/5 vs baseline 2/5; deepseek-v4-pro `aegis-level3` 1/5 vs baseline 2/5. The ratio therefore mixes protection cost with different failure modes and is not an effectiveness result.

## What this shows

- whether a real model can produce a graded submission on a deliberately non-standard task, and at what measured cost (wall clock, and oracle queries where the access mode counts them), provider-metered token cost where available, and broker-measured tool calls for mediated requests;
- whether the protected profile changes either, with the variance the repetitions actually exhibit;
- the probe's artifact size difference between the two profiles.

## What this does **not** show

- **No effectiveness claim.** N is small; the pass column describes what these configured agents could do, not what a protection prevented.
- No claim about other attacker classes or larger models.
- **The worker is not a container-isolated service.** Rows record the private network namespace, Landlock and seccomp policy; non-Linux fallback is not part of this pilot.
- Provider-metered totals exclude calls abandoned before usage arrived. The adapter's separate estimate is recorded in `aborted_tokens_estimate`; it is not added to the metered floor.
- Model and relay drift: rerunning later may produce different costs for the same model id.
